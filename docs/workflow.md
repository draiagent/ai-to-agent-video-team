# 八步任務流程

九項工序是工作分類，八步流程是專案進度與驗收關卡，兩者不可混淆。

| 步驟 | 輸入與動作 | 交付物 | 通過條件 |
|---|---|---|---|
| 01 定義任務 | 主題、受眾、目的、規格、預算 | 任務規格 | 關鍵資訊完整 |
| 02 腳本分鏡 | 將故事拆成逐鏡秒數與台詞 | 分鏡表 | 時長加總正確、每鏡有目的 |
| 03 視覺與聲音 | 鎖定角色、服裝、場景與音色 | 參考集與試音 | 辨識一致、品牌符合 |
| 04 節奏預覽 | 靜態圖搭配試配音 | 動態分鏡預覽 | 故事可理解、台詞說得完 |
| 05 動態鏡頭 | 依已確認分鏡製作 | 逐鏡影片 | 動作合理、角色穩定 |
| 06 剪輯與聲音 | 組裝、配樂、音效、字幕 | 粗剪版 | 人聲清晰、節奏與同步成立 |
| 07 調色驗收 | 統一色彩、檢查成片 | 精修版與問題紀錄 | 品質與品牌要求通過 |
| 08 交付保存 | 輸出與整理 | 成片、工程、來源與紀錄 | 可播放、可修改、可交接 |

失敗時回到相關工序。角色不一致回到角色參考或該鏡頭；聲音過大回到混音；故事不清楚回到分鏡。達重試或成本上限時停止該支線，回報替代方案與影響。

人保留劇情方向、情緒價值、符合形象三項判斷；Agent 可以提出建議，不得自行宣稱人工已核准。
