# 製片驗收表

本表供未來實作使用，不代表本專案已生成影片。

| 類型 | 驗收項目 | 必要證據 |
|---|---|---|
| 敘事 | 每鏡目的清楚、開頭與結尾相應 | 分鏡、審片紀錄 |
| 畫面 | 角色、服裝、產品與場景一致 | 逐鏡檢視紀錄 |
| 動態 | 無明顯變形或不合理動作 | 動態播放審查 |
| 聲音 | 人聲清晰、不爆音、音效對齊 | 試聽與音量檢查 |
| 字幕 | 繁體中文正確、時間同步 | 逐句比對 |
| 品牌 | Logo、語氣、色彩符合要求 | 品牌審核 |
| 輸出 | 片長、比例、解析度與格式正確 | 媒體資訊及播放測試 |
| 成本 | 重試與累計費用可追蹤 | 成本紀錄 |
| 人工判斷 | 劇情方向、情緒價值、符合形象 | 真實核准紀錄 |
| 交接 | 成片、工程、來源、證據完整 | 交付清單 |

結果填通過、失敗、未驗證或不適用，並附原因。技術檢查不能取代人工情緒與品牌判斷。
