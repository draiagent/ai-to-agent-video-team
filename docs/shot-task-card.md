# 一個鏡頭，一張工作圖卡

此為可複製的填寫模板，括號為欄位提示，不是已完成結果。

| 欄位 | 填寫內容 |
|---|---|
| 鏡頭編號與版本 | （例如 S03，版本 1） |
| 秒數與時間區間 | （開始、結束、長度） |
| 敘事目的 | （觀眾應理解什麼） |
| 參考素材 | （角色、產品、場景的檔案路徑） |
| 畫面與動作 | （主體動作、景別、運鏡） |
| 聲音安排 | （台詞、環境聲、音效與配樂） |
| 前後連續 | （服裝、光線、動作方向） |
| 驗收條件 | （可觀察、可判斷的標準） |
| 工具與成本 | （工具、單次費用與累計） |
| 重試上限 | （次數及超限處理） |
| 輸出與證據 | （素材路徑、檢查紀錄） |
| 狀態 | （待製作／待審／通過／需修正） |
